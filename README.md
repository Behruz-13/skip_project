# СКИП — Система Контроля Исполнения Поручений

Веб-приложение для контроля исполнения поручений в учреждении (10–15 пользователей).
Работает в браузере на ПК, телефоне и планшете. Интерфейс на русском языке.

**Стек:** Node.js + Express, React + Tailwind CSS (SPA, собран в `public/`), MySQL.

## Возможности

- 4 роли: Суперадмин, Руководитель, Помощник, Сотрудник (права — по разделу 12 ТЗ)
- Первоначальная настройка в браузере: создание суперадмина при пустой БД
- Поручения: создание, соисполнители, срок (дата + время, день недели), приоритет, основание
- Автоматическое ознакомление при открытии карточки (статус «Новое» → «В работе»)
- Промежуточные обновления, отчёт, закрытие / возврат на доработку
- Запрос продления срока с одобрением / отклонением (срок переносится автоматически)
- Редактирование, смена срока, исполнителя и соисполнителей с записью в историю
- Чат в карточке поручения, счётчик непрочитанных сообщений
- Личные задачи сотрудника («Личная» / «На контроль»)
- Фильтры (Все, Новые, В работе, На проверке, Просроченные, Закрытые) и поиск
- Календарь на месяц, дашборд с кликабельной статистикой по исполнителям
- Колокольчик уведомлений (просрочено, скоро срок, ожидают проверки, продления, сообщения, возвраты)
- Экспорт в Excel (.xlsx): «Поручения», «Статистика по исполнителям», «История»
- Предложения суперадмину
- Управление пользователями: создание, редактирование, сброс пароля, деактивация
- Уведомления в Telegram (необязательно, при заданном `TELEGRAM_BOT_TOKEN`)

## Развёртывание на ISPmanager 6

1. В ISPmanager создайте сайт `controluzembassyby.uz` с обработчиком **Node.js**.
2. Загрузите файлы репозитория в корень сайта (на GitHub: «Code → Download ZIP»,
   либо `git clone`). Папка `public/` уже содержит собранный интерфейс — собирать ничего не нужно.
   Папку `client/` (исходники интерфейса) загружать необязательно.
3. Создайте базу данных MySQL (ISPmanager → Базы данных) и пользователя к ней.
4. (Необязательно) Выполните `schema.sql` в phpMyAdmin. Если этого не сделать,
   приложение само создаст таблицы при первом запуске.
5. Создайте в корне сайта файл `.env` по образцу `.env.example`:
   ```
   PORT=10010
   DB_HOST=localhost
   DB_USER=ваш_пользователь_бд
   DB_PASSWORD=ваш_пароль_бд
   DB_NAME=имя_базы
   DB_TIMEZONE=+05:00
   JWT_SECRET=случайная_длинная_строка
   COOKIE_SECURE=true
   APP_URL=https://controluzembassyby.uz
   TELEGRAM_BOT_TOKEN=
   ```
   `COOKIE_SECURE=true` — если сайт открывается по HTTPS (рекомендуется); при работе по HTTP — `false`.
   `DB_TIMEZONE` — часовой пояс учреждения (Ташкент `+05:00`, Минск `+03:00`).
6. В панели ISPmanager выполните `npm install` (команда `ispmanager-custom-command`)
   и перезапустите обработчик Node.js. Точка входа — `app.js` (`npm start`).
7. Откройте сайт в браузере — появится форма создания суперадмина.

Резервный способ создать суперадмина из консоли:
```
node scripts/create-admin.js admin Пароль123 "Фамилия Имя Отчество" "Должность"
```

## Уведомления в Telegram (необязательно)

1. Создайте бота через @BotFather и укажите токен в `.env` (`TELEGRAM_BOT_TOKEN`).
2. Перезапустите приложение.
3. Каждый пользователь пишет боту `/start`, получает свой chat_id и вводит его
   в системе: меню с именем → «Telegram-уведомления».

Бот присылает: новые поручения, отчёты на проверку, возвраты, решения по продлению,
сообщения в карточке, а также ежедневно после 09:00 — «скоро срок» (за 3 дня) и просроченные.

## Разработка

```
npm install                 # зависимости сервера
cp .env.example .env        # и заполнить
npm start                   # сервер на PORT (по умолчанию 3000)

npm run build               # пересобрать интерфейс client/ → public/
npm run dev:client          # dev-сервер интерфейса с проксированием /api на :3000
```

## Структура

```
app.js                  точка входа Express
schema.sql              схема БД
src/db.js               пул MySQL и создание таблиц
src/auth.js             JWT (cookie skip_token, 7 дней), вход/выход
src/setup.js            первоначальная настройка
src/items.js            поручения
src/users.js            пользователи
src/suggestions.js      предложения
src/telegram.js         Telegram-уведомления и ежедневные напоминания
scripts/create-admin.js создание суперадмина из консоли
client/                 исходники интерфейса (React + Tailwind, Vite)
public/                 собранный интерфейс (отдаётся сервером)
```
